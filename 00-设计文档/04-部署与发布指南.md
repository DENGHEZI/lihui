## 一、服务端 `03-lh-server`

### 1.1 环境要求
- Node.js **≥ 18**（推荐 20 / 22），**零外部依赖**，不需要 `npm install`。
- 可外网访问（用于调用百度地图 Web 服务 API 与模型 API）。

### 1.2 启动
```bash
cd D:/鲤慧-LiHui/03-lh-server
cp .env.example .env          # Windows: copy .env.example .env
#   编辑 .env，至少填 BAIDU_AK 与一个大模型 Key
node src/app.js
# 控制台输出：鲤慧服务端已启动 http://0.0.0.0:8809
```

### 1.3 验证
```bash
curl http://127.0.0.1:8809/api/v1/health
curl http://127.0.0.1:8809/api/v1/ip/locate
curl "http://127.0.0.1:8809/api/v1/map/poi/search?query=药店&lng=112.938814&lat=28.228209"
```

### 1.4 生产部署
- **PM2**：`pm2 start src/app.js --name lihui-server`
- **systemd**（Linux）：`systemctl enable lihui-server`
- **Windows 常驻**：用 `nssm install lihui-server "<node路径>" "src/app.js"`
- **反向代理**：Nginx 转发 `/api/` → `127.0.0.1:8809`，必须开启 HTTPS 并透传
  `X-Forwarded-For`（IP 自动锚定依赖它）。

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:8809;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Real-IP $remote_addr;
}
```

### 1.5 百度地图 AK 白名单
生产环境请在百度地图开放平台把服务端 AK 的 **IP 白名单** 设为你的服务器出口 IP，
并确认已开通「IP 定位」「地理编码」「逆地理编码」「地点检索」「路线规划」「天气查询」服务。

## 二、多端 APP `01-lh-uniapp-多端APP`（HBuilderX）

### 2.1 打开工程
HBuilderX → 文件 → 打开目录 → 选择 `D:/鲤慧-LiHui/01-lh-uniapp-多端APP`
> 该工程基于 HBuilderX 官方 `uniapp_vue/default.zip` 骨架，可直接识别。

### 2.2 运行调试
| 目标 | 操作 |
|---|---|
| Android 真机 | 手机开 USB 调试 → 运行 → 运行到手机或模拟器 → 运行到 Android App 基座 |
| HarmonyOS | 运行 → 运行到手机或模拟器 → 运行到鸿蒙（需 DevEco Studio + 已签名基座） |
| iOS 真机 | 需 Mac + Xcode；运行 → 运行到 iOS App 基座 |
| H5 预览 | 运行 → 运行到浏览器（最快验证 UI） |

### 2.3 发行打包
1. **Android**：发行 → 原生App-云打包 → 选 Android → 上传 `.keystore` → 得到 `.apk`。
2. **iOS**：发行 → 原生App-云打包 → 选 iOS → 上传 `.p12` + `.mobileprovision` → 得到 `.ipa`。
3. **HarmonyOS**：发行 → 原生App-云打包 → 选 HarmonyOS → 需 DevEco 生成的 `.cer` / `.p7b`。

### 2.4 关键配置（`manifest.json`）
```jsonc
"app-plus": {
  "distribute": {
    "android": { "packagename": "com.lihui.lifecircle", "permissions": ["<uses-permission android:name=\"android.permission.ACCESS_FINE_LOCATION\"/>"] },
    "ios": { "idfa": false, "dSYMs": false },
    "sdkConfigs": {
      "maps": { "baidu": { "appkey_ios": "你的iOS端AK", "appkey_android": "你的Android端AK" } }
    }
  }
}
```
> 说明：底图渲染走 uni-app 内置 `<map>` 组件（Android 默认百度/高德由 `sdkConfigs.maps` 决定）；
> **业务数据**（POI/路线/体检）统一走服务端中转，端的 AK 仅用于底图 SDK 初始化。

### 2.5 鸿蒙适配
- `harmony-configs/` 内为鸿蒙模块配置模板（`module.json5` 片段、权限声明）。
- uni-app x / 鸿蒙要求 HBuilderX ≥ 4.5；老版本请升级。

## 四、MCP Server `04-lh-mcp-servers`

每个子目录是一个可独立运行、可独立发布的 MCP Server。

```bash
node 04-lh-mcp-servers/baidu-map/index.js        # stdio 模式，等待 JSON-RPC
```

### 4.1 接入 Claude / 任意 MCP 客户端
```jsonc
{
  "mcpServers": {
    "lh-baidu-map": {
      "command": "node",
      "args": ["D:/鲤慧-LiHui/04-lh-mcp-servers/baidu-map/index.js"],
      "env": { "BAIDU_AK": "<你的百度AK>" }
    }
  }
}
```

### 4.2 从 ModelScope 拉取更多 MCP
服务端已内置检索与安装接口：
```bash
curl "http://127.0.0.1:8809/api/v1/mcp/registry/search?keyword=地图"
curl -X POST http://127.0.0.1:8809/api/v1/mcp/install \
  -H "Content-Type: application/json" \
  -d '{"id":"modelscope/xxx","installType":"npm","installRef":"包名","autoStart":true}'
```
也可以在 ModelScope（https://modelscope.cn/mcp）手动下载后，把目录放进
`04-lh-mcp-servers/`，再在 `03-lh-server/data/mcp.json` 登记即可被 Agent 发现。

## 六、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `/api/v1/ip/locate` 返回内网 IP | 未走反向代理 / 未透传 `X-Forwarded-For` | Nginx 加 `proxy_set_header X-Forwarded-For` |
| 百度接口报 `AK 校验失败` | AK 白名单 / 服务未开通 | 到百度地图开放平台核对 |
| 小程序 `api.map.baidu.com 不在合法域名` | 未配置域名 | 见 3.2 |
| APP 端地图白屏 | 未配 `sdkConfigs.maps.baidu` | 见 2.4 |
| MCP Server 状态 `error` | Node 版本过低 / 端口占用 | 看 `data/logs/` 与 `/api/v1/mcp/list` 的 `error` 字段 |
| 语音无声音 | 系统 TTS 引擎缺失 / `autoSpeak` 关闭 | 「我的→语音设置」切换引擎 |
