### 踩坑经验（复用价值高）
1. **百度改版存量 bug**：directionlite/v1/* 的 `coord_type=3` 全线报 `[coord_type] format is invalid`；正确写法 **`coordtype`（无下划线）+ `gcj02`** 字符串。routematrix/v2/walking 同样收 `coordtype=gcj02`，返回是 `{distance:{text,value},duration:{text,value}}` 对象式结构，解析需双形态兼容。place/v2 的 coord_type=3 是否同挂无法验证（302 遮蔽），已加自适应防御（status=2 且 msg 含 coord → 自动换 coordtype 重试）。
2. **令牌桶死锁模式**：`tokens += floor(elapsed/interval); last = now` 若每轮都执行，elapsed 恒 0 → 令牌永不回流 → 并发全挂死。修法：只在 elapsed≥interval 时累积并 `last = now - (elapsed % interval)`。
3. **工作目录漂移**：Bash 调用间 cwd 会漂回会话根目录（本身是个 git 仓库！），**每条 git 命令必须显式 `cd /d/鲤慧-LiHui` 前缀**，否则 commit/status 打到会话仓库（本会话两次踩：commit 漂移、add -A 漂移被 nul 文件中断）。
4. **CI 中文路径**：git core.quotepath 默认转义中文目录 → 语法检查假失败，循环必须 `git -c core.quotepath=off ls-files '*.js'`。
5. **双端推送规范**：GitHub 用 PAT 显式 URL push（不用 -u），推完 master 再补一条 `master:main` 同步镜像分支；CI 会双分支各跑一次。
