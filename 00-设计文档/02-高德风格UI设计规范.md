# 鲤慧 · 高德地图风格 UI 设计规范

> 参考对象：**高德地图 App**（非照搬，取其设计语言）
> 关键词：**底部抽屉、胶囊标签、悬浮圆钮、蓝色主色、大留白、细边框**

---

## 1. 设计原则（从高德提炼的 6 条）

1. **地图是主角，UI 是浮层。** 所有面板都是「浮」在地图上的，绝不整屏铺满遮挡地图。
2. **底部抽屉（Bottom Sheet）承载一切信息。** 三段式：折叠（80px 把手）/ 半屏（45%）/ 全屏（90%）。
3. **搜索框永远在顶部，永远是大圆角胶囊。** 左侧返回/定位，右侧语音麦克风。
4. **操作区靠下、拇指可达。** 主按钮固定在抽屉底部，距底部 16px + 安全区。
5. **圆角一致：卡片 16px，按钮 999px（胶囊），小标签 8px。**
6. **颜色只用三种语义：主色（导航蓝）、成功（可达绿）、警示（拥堵红）。**

## 2. 色彩令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--lh-primary` | `#1677FF` | 主按钮、选中态、路线主色 |
| `--lh-primary-dark` | `#0E5FD8` | 按下态 |
| `--lh-primary-soft` | `#EAF2FF` | 主色浅底（标签、选中行） |
| `--lh-success` | `#00B96B` | 可达、达标、绿波 |
| `--lh-warning` | `#FF8A00` | 待改善、等待 |
| `--lh-danger` | `#F5222D` | 拥堵、短板、错误 |
| `--lh-text` | `#1A1A1A` | 主文字 |
| `--lh-text-sub` | `#646A73` | 次要文字 |
| `--lh-text-weak` | `#8F959E` | 辅助/占位 |
| `--lh-line` | `#EDEFF2` | 分割线、边框 |
| `--lh-bg` | `#F4F5F7` | 页面底色 |
| `--lh-card` | `#FFFFFF` | 卡片/抽屉 |
| `--lh-mask` | `rgba(0,0,0,.45)` | 遮罩 |

> 关怀模式（老年人）覆盖：`--lh-text` → `#000`，字号 ×1.25，`--lh-line` → `#D8DCE2`（边框更明显）。

## 3. 字阶

| 名称 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| H1 | 22 / 30 | 600 | 页面主标题、体检总分 |
| H2 | 18 / 26 | 600 | 抽屉标题 |
| Body | 15 / 22 | 400 | 正文 |
| Caption | 13 / 18 | 400 | 辅助说明 |
| Mini | 11 / 16 | 400 | 角标、距离单位 |

---

## 4. 间距与栅格

基准 **4px**；常用：`4 / 8 / 12 / 16 / 20 / 24 / 32`。
页面左右安全边距 **16px**；卡片内边距 **16px**；卡片间距 **12px**。

## 5. 组件规范

### 5.1 顶部胶囊搜索框
```
高 48px / 圆角 24px / 背景 #FFF / 阴影 0 2px 12px rgba(0,0,0,.08)
[←]  搜索目的地、公交、地铁…            [🎙]
左侧图标 20px，右侧麦克风 20px，占位文字 --lh-text-weak
```

### 5.2 底部抽屉
```
把手：宽 36 高 4 圆角 2 背景 #DDE0E4，居中，上间距 8
圆角：上左/上右 20px
阴影：0 -4px 20px rgba(0,0,0,.08)
三段吸附：80px / 45% / 90%
```

### 5.3 悬浮圆形按钮（FAB）
```
56×56 / 圆角 50% / 背景 #FFF / 阴影 0 4px 16px rgba(22,119,255,.25)
图标 24px 主色；定位按钮固定右下，距底 120px、距右 16px
```

### 5.4 胶囊标签
```
高 28px / 内边距 0 12px / 圆角 999px / 边框 1px --lh-line
选中：背景 --lh-primary-soft，文字 --lh-primary，边框 --lh-primary
```

### 5.5 主按钮
```
高 48px / 圆角 999px / 背景 --lh-primary / 文字 #FFF 16px 600
按下：--lh-primary-dark；禁用：#C8CDD4
```

### 5.6 生活圈评分环
```
直径 120px / 轨道 10px #EDEFF2 / 进度 10px 圆角
颜色按分值：≥85 绿 / 60-84 蓝 / 40-59 橙 / <40 红
中心：分数 32px 600 + 「分」12px
```

### 5.7 POI 行
```
[类别圆图标 40]  名称 15px 600           距离 13px 主色
                 地址 13px 次要    -----  [标签: 医保/24h/优惠]
```

### 5.8 语音对话
```
底部中央 大圆麦克风 72×72 主色渐变
说话中：外圈 3 层呼吸波纹（1.6s 循环）
播报中：波形条 5 根上下跳动
```

## 6. 地图视觉

| 元素 | 规范 |
|---|---|
| 底图 | 浅色底图（百度地图 `light` 风格），道路 `#FFFFFF`、水系 `#C8E4FF`、绿地 `#D9F0DC` |
| 我的位置 | 蓝色圆点 + 白描边 + 外圈 40% 透明光晕 |
| 15 分钟等时圈 | `rgba(22,119,255,.10)` 填充 + `#1677FF` 1px 虚线描边 |
| 路线主色 | 步行 蓝 `#1677FF`；骑行 绿 `#00B96B`；驾车 蓝 `#1677FF` + 拥堵红 `#F5222D` 分段 |
| POI 气泡 | 白底 12px 圆角 + 主色描边 + 阴影，内容「名称 + 距离」 |

## 7. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 抽屉吸附 | 260ms | `cubic-bezier(.16,1,.3,1)` |
| 页面转场 | 220ms | ease-out |
| 按钮按下 | 120ms | ease |
| 语音波纹 | 1600ms | 循环 |
| 数字滚动（分数） | 600ms | ease-out |

## 8. 端上落地方式

- **uni-app**：`01-lh-uniapp-多端APP/uni.scss` 内定义同名 SCSS 变量，页面直接 `var(--lh-primary)`。
- **小程序**：`02-lh-wechat-mp/app.wxss` 内定义同名 CSS 变量（小程序支持 `var()`）。
- **统一来源**：`00-设计文档/设计令牌/tokens.css`，三端复制粘贴，禁止各端私自改色值。
