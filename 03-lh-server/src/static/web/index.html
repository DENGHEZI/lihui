手机端调用方式（utils/request.js 封装）：请求头带 X-Device-Id: 设备号；已登录再带 Authorization: Bearer <token>（+X-Auth-Token 双头兜底反代剥头）；读响应头 X-Token-Cost 显示本条花费。响应统一 {"code":0,"msg":"ok","data":…}，非 0 封装直接抛 body.msg（端上 toast 即真实原因）。限流 429 时响应含 X-RateLimit-* 头。网页端同源直连、登录后自动携带，同一套封装口径。
