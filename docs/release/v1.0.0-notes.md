# 🐟 鲤慧 LiHui · V1.0.0 首个正式发行版

**15 分钟，看清你的生活半径。** 基于百度地图开放能力的「15 分钟生活圈」智能体检与规划助手。

## 📦 本版包含

- **📱 微信小程序**（测试版已上传微信平台，版本号 1.0.0，总包 217.9 KB 编译通过）
  - 地图主页 / 生活圈体检 / 步行等时圈 / 鲤慧商城 / 多模态识图（GLM-4.6V）/ 语音对话与播报 / Memory 安全运维
  - 附件 `v1.0.0-mp-preview-qr.png` 微信扫码即打开测试版；后台「版本管理」可设为体验版
- **🌐 网页版 Premium 仪表盘**
  - 自动定位（GPS → IP 兜底 → 手动城市）→ 实时天气 → 六类设施体检 → 真实路网等时圈与盲区 → 便民速查 → 百度真实店源 → 能力全景 → Memory
- **🗺 百度底图测试页** `/map-home`：服务端伪造 Referer 代理 JS API 与瓦片，AK 零下发
- **🛡 密钥零暴露体系**：蜜罐假密钥 / 脱敏出网 / 服务端代理 / `/health` 诊断探针
- **🧠 Memory 人机协同安全运维**：AI 只建议不执行 · 沙箱验证 · 人工批准产出工件
- **📦 服务端 Node.js 零依赖** · 微信云托管自动构建 · Gitee/GitHub 双远程

## 🚀 快速开始

```bash
node 03-lh-server/src/app.js   # → http://localhost:8809/
```

小程序：微信开发者工具导入 `02-lh-wechat-mp`（AppID `wxfc45acb99d454f8a`）。
