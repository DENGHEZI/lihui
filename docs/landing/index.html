真实步行等时圈

不是直线圆——沿真实人行路网算出「15 分钟能走多远」，盲区一眼看穿。

🛒

真实店源双通道

附近 3km 按定位实时拉、本城热门城市级检索；百度 POI 真实店名/坐标/电话，落盘缓存护配额。

🥡

外卖平台识别

每家店挂美团/饿了么/抖音「搜这家店」深链；配了真实接口可自动核实在架/价格/评分，绝不编造数据。

🚶

真实步行距离

批量矩阵实测「走过去要几分钟」，隔河高架不再骗人；带「真实步行」徽章。

🧠

Memory 长记忆

JSON / SQLite 双驱动的用户画像与记忆沉淀，常搜类目自动上浮，人机协同安全运维。

🤖

Agent 智能助手

多模态识图、语音对话与播报、工具调用；关怀模式下自动放慢语速、简化表达。

🔐

RBAC + 感知限流

三角色最小权限（guest/user/admin）、scrypt 口令、HMAC 无状态令牌；令牌桶按身份限速并下发标准头。

🛡️

蜜罐安全体系

假密钥诱捕、IP 自动封禁、出网脱敏、CSP 浏览器沙箱、多 AK 池自愈轮换；459 条攻击用例全绿。

🧩

MCP 协议扩展

系统架构

三端接入 · 一颗零依赖核心 · 安全默认

📱

端（三端同源）

  • 微信小程序（主包 217KB）
  • uni-app 多端 APP（Android / HarmonyOS / iOS）
  • Web Premium 仪表盘 + 百度底图页
  • 所有百度能力经服务端中转，AK 零下发
⚙️

服务端（Node 零依赖）

  • 纯 Node 标准库 HTTP 服务，node src/app.js 即起
  • 体检引擎 / 等时圈 / 店源 / 商城 / 订单 / Agent / Memory
  • JSON / SQLite 双驱动存储 + 多级缓存
  • 多 AK 池：配额打满自动冷却切换，0 点自愈回归
🛡️

安全（默认开启）

  • RBAC 三角色 + scrypt 口令 + HMAC 无状态令牌
  • 蜜罐假密钥诱捕 + IP 自动封禁 + 出网脱敏
  • CSP 沙箱 + 角色感知限流（标准限流头）
  • 459 条 E2E 攻击用例全绿（SQLi / XSS / CRLF / 溢出）

快速开始

三步跑起来，本地体验完整能力

克隆仓库

# Gitee（国内快） git clone https://gitee.com/deng-he-ziyan/lihui.git # 或 GitHub git clone https://github.com/DENGHEZI/lihui.git

配置百度地图 AK

cd lihui/03-lh-server cp .env.example .env # 在 .env 中填写 BAIDU_AK（百度控制台创建「服务端」类型） # 支持多把钥匙逗号分隔：BAIDU_AK=ak1,ak2,ak3

启动服务

node src/app.js # → http://localhost:8809 Web 仪表盘可直接打开 # 首次启动自动播种管理员：admin（务必改口令）

小程序端用微信开发者工具导入 02-lh-wechat-mp 目录即可 · 详细文档见仓库 README 与 00-设计文档
