一句话说清

鲤慧在你同意后才会记录用于「个性化推荐」的行为数据（搜过什么、聊过什么话题、点过哪些店、发起过导航）；未同意时功能照常可用，只是不做个性化。你可随时导出或删除你的全部数据。

我们收集什么、为什么

  • 必需设备标识（Device ID）——在同一设备上记住你的偏好与同意状态。由端上随机生成并本地持久化，不含姓名、手机号等身份信息。
  • 必需位置信息（经纬度）——周边搜索、路线规划、15 分钟生活圈体检。仅用于当次请求的计算，不落库、不形成轨迹历史。
  • 需同意搜索关键词与对话主题类目——个性化排序与回复。只存离散关键词与类目计数，带时间衰减自动遗忘（约 30 天半衰期）。
  • 需同意点店 / 导航行为（POI 名称与坐标）——「常去地点」加权推荐。最多保留 30 条，随时间衰减自动清理。

我们不收集

  • 姓名、手机号、身份证等实名信息（未登录时）；
  • 精确轨迹 / 历史位置序列；
  • 通讯录、相册、剪贴板。

如何存储

行为画像存于服务端数据目录（profiles），可随时导出或彻底删除；对话会话默认保留最近 40 条用于上下文。

你的权利（自助操作）

  • 同意 / 撤回：网页版底部横幅可同意；下方「撤回同意」立即停采并删除画像；
  • 数据导出（可携权）：导出你的画像、同意记录与 Token 用量；
  • 数据删除（被遗忘权）：删除你的画像、同意记录与 Token 记录。
